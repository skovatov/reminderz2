SMS Reminder Service — Opt-In Information

This page describes how a user enrolls to receive automated SMS reminders from Sam Kovatovich's personal reminder service.

How Enrollment Works

The sole user opts in by manually entering their mobile phone number into the application's configuration file (reminders.json). This action constitutes explicit consent to receive automated SMS reminder messages.

Example Configuration

{"to_number": "+16232995016", "sms_enabled": true}

What You're Consenting To

By adding your number to the configuration, you agree to receive automated SMS reminder messages. Message frequency varies based on scheduled reminders. Message and data rates may apply.

Opt-Out

Reply STOP to any message to unsubscribe. Reply START or UNSTOP to re-enroll. Reply HELP for assistance.
