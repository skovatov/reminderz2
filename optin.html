Reminderz — SMS Enrollment

Reminderz is a personal automated SMS notification system operated by Sam Kovatovich (sole proprietor). It sends scheduled maintenance and calendar reminders to a single registered mobile phone number.

How Enrollment Works

The system operator (Sam Kovatovich) enrolls a phone number by manually entering it into the application configuration file (reminders.json). By adding the number to the configuration, the operator explicitly consents to receive automated SMS reminder notifications from this system.

Example configuration (opt-in step)

{
  "to_number": "+16232995016",
  "sms_enabled": true
}

No third parties are enrolled. The sender and sole recipient are the same individual.

Consent Language

By entering a mobile number into the Reminderz configuration file, the user consents to receive automated SMS reminder messages from Reminderz (operated by Sam Kovatovich) at the number provided. Message frequency varies based on configured reminder schedules. Message and data rates may apply.

Opt-Out

Reply STOP to any message to unsubscribe. You will receive a confirmation and no further messages will be sent. Reply START or UNSTOP to re-enroll.
